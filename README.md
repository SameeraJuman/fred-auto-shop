How to Run 
Step 1. Open Visual Studio Code--- Open the respective Folder

Step 2
Open the terminal
In VS Code:
1. Click Terminal in the top menu.
2. Select New Terminal.
3. Make sure the path is correct


Step 3. 
Install dependencies (only when necessary)
If its your first time running the project, or the dependencies have changed
run (npm.cmd install) in the terminal  
u dont need to do this every time 


Step 4. Start the Vite server
In the terminal run (npm.cmd run dev) press enter and boom
